# Java EE registration and login

User registration and login built the MVC way: JSP pages, a JavaBean per form, servlets as controllers, and DAOs over Apache Derby.

Coursework for **CSC584 Enterprise Programming (Assignment 2: Java Application Deployment)**, Bachelor of Information Technology (Hons.), Universiti Teknologi MARA (UiTM), 2021. Individual assignment.

## Stack

JSP, Servlets, JavaBeans, DAO pattern, Apache Derby (Java DB). A NetBeans Ant web project, deployed on GlassFish.

## Running it

Open the folder in NetBeans with GlassFish, start Java DB, and create a database named `customers` (connection settings in `src/java/util/DBConnection.java`).
